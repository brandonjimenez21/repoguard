# Security policy

## Supported versions

Only the latest published `0.x` release is supported. There is no LTS branch yet.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead, use
[GitHub Security Advisories](../../security/advisories/new) for this repository, or report
privately to the maintainer. You should get an initial response within a few days.

Once a fix is available it will ship as a patch release and the advisory will be published
alongside it.
